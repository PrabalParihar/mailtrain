# Workspace API keys Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for native implementation and one fresh whole-slice review.

**Goal:** Deliver REQ-049 scoped hashed keys, one-time display, atomic rotation/revocation and shared API limits without weakening consent or send approval.

**Architecture:** A narrow definer function resolves a high-entropy bearer digest to one tenant. Every call verifies current issuer membership, key expiry/revocation and resource scope. Session-only key management stores only digest/prefix; idempotency receipts omit secrets, so a lost issue response requires explicit rotation. PostgreSQL serializes rolling 60-second workspace/credential rate accounting. Queued creation jobs retain and recheck the credential binding.

**Tech Stack:** Existing Next/PostgreSQL/Zod/crypto/Playwright, no dependencies.
