# Selected asset licenses

Inter is distributed locally from the exact pinned `@fontsource/inter` package. Its bundled LICENSE attributes The Inter Project Authors and uses SIL Open Font License 1.1. Source/license: https://github.com/rsms/inter.

Lucide React icons use the exact pinned `lucide-react` distribution, whose bundled LICENSE is ISC and attributes Lucide Icons and Contributors. Source/license: https://github.com/lucide-icons/lucide.

Lettercape geometric SVG marks are repo-native original constructions from the approved visual direction. SVG wordmarks use selectable text and the specified font stack; they need Inter installed when exported as standalone SVG. Production print/export can embed the licensed font or convert the exact reviewed font to outlines.

These license checks cover current font/icon distributions, not trademark clearance or rights in user-uploaded customer assets. Customer media and generated images require their own provenance/rights checks before publication.
