# Isolated frozen browser exports

This worker accepts only signed immutable-artifact PNG/PDF requests. It receives no database, session, AI, sending or billing credentials. The app checks workspace and role again, serializes cache admission per workspace and stores immutable export bytes under revision, format and renderer profile. A finite storage allowance is required; existing exports remain available when new admission is full. Local-development receipts use a distinct platform profile.

Verified cached reads precede admission. Uncached renders use immediate workspace try-lock and at most2 nonblocking render slots per app process; retryable busy responses release their database connections promptly. This bounds local shared-pool use and does not replace distributed durable queue/fairness acceptance. Request interruption aborts transport/browser work and prevents committing new bytes afterward. Worker error bodies are bounded and only known permanent artifact codes are reflected; transient outages remain retryable and unauthenticated output is refused. Editor exports abort on edit/unmount and check the originating acknowledged anchor immediately before downloading.

`Dockerfile` pins Node 24.12.0 and Playwright 1.63.0. Chromium must report 153.0.8010.12. The runtime is UID1001, browser sandbox enabled, script/service-worker disabled, and all browser resource routes aborted. Cache profile changes are mandatory whenever browser, fonts, renderer settings or output behavior change. The deployed image digest, fonts manifest and platform sandbox/egress/resource settings must be recorded in release evidence; the code profile alone does not certify a production runtime.

The checked-in `seccomp-profile.json` is the unchanged official Playwright v1.63.0 profile from [Microsoft Playwright](https://github.com/microsoft/playwright/blob/v1.63.0/utils/docker/seccomp_profile.json), under that project's Apache2.0 license. SHA256: `cc3e61cabda6bbc1e53e54d27ba4d55a9d3be829b6dd1a596f4a7b31b1cc7849`. It permits Chromium user namespaces within Docker's syscall filtering. Do not disable Chromium sandboxing or run privileged to bypass a host failure.

Fixture execution uses `--network none`, a read-only filesystem, bounded tmpfs, 1GiB memory, 2CPUs and 256PIDs, with only a public test script and output directory mounted. The child server generates a private key in memory, binds loopback and has no application credentials. Actual HTTP probes cover output signatures, replay, input/dimension/capacity limits and a zero-hit image/font/script/frame tripwire. Fixture-only mode requires an explicit flag, nonproduction environment and loopback binding.

Production defaults refuse startup until all13 full Baseline A gates have build-bound evidence. Railway sandbox, private networking, egress firewall, storage/retention allowance, 50-render load, durable render queues, cancellation/retry, platform operations and measured total costs still require acceptance before activation. No claim of actual Outlook/Gmail captures is made by these browser simulations.
